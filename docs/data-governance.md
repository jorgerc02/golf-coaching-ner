# Data governance

This repository is intentionally data-free.

Research code and research data have different publication requirements.
Public source code can explain collection, annotation, conversion, and
evaluation without redistributing the underlying records.

Before using any corpus, verify:

- the source permits the planned research use;
- ethical-review and university requirements are satisfied;
- personal or linkable identifiers are minimised;
- retention and deletion rules are documented;
- access is limited to approved researchers; and
- public outputs contain only authorised or aggregate information.

Platform content identifiers can be linkable even when usernames are removed.
Transcripts may also contain names, locations, or other information spoken in
the original content. Removing obvious profile fields is therefore not a
complete anonymisation method.
